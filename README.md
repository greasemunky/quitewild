# Quite Wild website

Landing page for Quite Wild, small-group safaris in Kabini and Nagarahole hosted by Neel Basu.

## Files

- `index.html`: the whole page (styles included)
- `assets/`: photos and the WhatsApp QR code

## Put it online with GitHub Pages

1. Create a new public repository on GitHub, for example `quitewild`.
2. Upload `index.html` and the `assets` folder to the repository.
   On github.com: **Add file → Upload files**, drag both in, then **Commit changes**.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose the `main` branch and the `/ (root)` folder, then **Save**.
5. After a minute or two the site is live at `https://<your-github-username>.github.io/quitewild/`.

## Use your own domain (optional)

1. Buy a domain, for example `quitewild.in`.
2. In **Settings → Pages → Custom domain**, enter it and save.
3. At your domain provider, add the DNS records GitHub shows you, then tick **Enforce HTTPS** once it's available.
